# v0.27 original envoy artwork

`envoy.png` is original AI-assisted artwork generated for Shattered Crowns on 2026-11-15: an unnamed civilian envoy holding a sealed letter at Ironmere. It does not portray Lady Elowen. `envoy.webp` is its reviewed 1254×1254 runtime derivative. `integrity.json` locks the source and runtime bytes. The decorative letter/seal SVG is authored in `src/v027/envoy-presentation.js`.

The portrait adds 305,504 compressed bytes and 6,290,064 decoded RGBA bytes. Combined with v0.26, the locked runtime packs total 2,481,420 compressed bytes and 31,454,308 decoded bytes. The integrity ceilings are 4 MiB compressed and 32 MiB decoded. This is a DOM portrait; it adds no world-rendering pass and does not block simulation if it fails to load. These are asset accounting figures, not measured process memory.
