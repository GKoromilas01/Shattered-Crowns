# Art and systems roadmap (written 24 Nov 2026, v0.65 session)

Owner direction: gradual, a few visible changes per version, each checkable in ~30 s; ask the owner before each version.

## Art to make (about 70 tokens per sprite)
1. Foreign armies in their own dress: soldier + archer for each of the 3 neighbouring kingdoms (6). Today every enemy soldier uses the single `unit_raider` sprite. Bandits keep the ragged look.
2. Siege machines (after walls and war exist, ~v0.68): ram, catapult, trebuchet, ballista, siege tower.
3. Defence pieces: gatehouse, corner towers, boiling-oil pot.
4. People: King's Guard (own uniform), mounted knight, monk/priest, merchant with cart, children, sheep.
5. Military buildings: barracks, blacksmith/armoury, stables, archery range, hospital, prison and stocks.
6. Building upgrades: every building gets 2-3 more looks per upgrade level, built gradually (owner request, 24 Nov).
7. Terrain: water and shore, trees, rocks, hills, snow and desert variants. Effects: fire, smoke, arrows, rubble.
Already stored for later versions in `assets/v065/later-originals/`: tavern and inn, monastery, galley, frigate, cattle pasture, red deer, tournament field, slum quarter, cave with witch's hut, House of Roses.

## Systems still needed
War with real cost and reward (see DESIGN_GROWTH_AND_WAR.md), upgrade tiers per building, rectangular wall built in paid segments (test pathfinding first), law and justice, religions and politics, server for multiplayer, keyboard-shortcuts help page.
