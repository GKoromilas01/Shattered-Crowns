# Art and sound options — 22 November 2026

Owner priority: one coherent medieval town, without visible switches between AI providers or release versions. This is research and a recommendation, not authorization to purchase/generate assets or change the approved art direction. See ART_DIRECTION.md and LEONARDO_PLAN_NOTES.md.

## Recommendation

Keep Essential for now; integrate and polish the existing paid set before regenerating it. v052's Chapel/School improvement uses existing originals that the renderer bypassed. The one-minute Leonardo music avoids the repeated extended-copy joins without buying anything. A subscription upgrade mainly changes capacity; it does not automatically improve a chosen model's images.

For future work, identify the few weakest/highest-impact assets, estimate a small batch's actual generator cost, then compare the upgrade quote and top-up. Avoid replacing the whole library simply because a new model is available.

## Keep one visual identity

Select a small reference sheet from approved existing assets: a house, public building, worker, vegetation and a deposit. Keep warm limestone, timber, muted terracotta/slate, olive vegetation, natural light and the established painted finish. Specify the same camera/projection, light direction, shadow treatment, scale, crop/transparency and edge softness.

Edit the original when only an entrance, roof or material needs improvement; avoid asking a new model to reinvent everything. Reference images guide style but do not guarantee it. Compare every sample beside the existing town at actual game zoom and as its command icon. A sharper standalone image can still be a worse game asset if it clashes or hides workers. Record provenance and licensing through the existing asset process.

## Keep one sound identity

Current decision: four original one-minute Leonardo recordings, no synthesized themes in active rotation, no copy-paste extension edits. Preserve all sources for later use. Future longer tracks should keep an agreed instrumental/mood palette and be generated as complete compositions at a selected duration; the current Musicv1 supports1–10minutes. A prompt for a similar style does not guarantee the exact same melody. Keeping the precise theme may need a genuine arrangement rather than repeated audio segments.
