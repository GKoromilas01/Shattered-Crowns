# Visual explorations — Sand Labs / Shattered Crowns

Original image-generation concepts requested by Giannis on 2 November 2026. Retained as design references; these files are not part of the three-file production Pages artifact.

- [Sand Labs logo](sand-labs-logo.png): first company mark; Giannis liked it and subsequently suggested a more mysterious Oracle-of-Delphi-inspired direction for future exploration.
- [Shattered Crowns logo](shattered-crowns-logo.png): fractured crown, castle and shield identity.
- [City art direction](city-art-direction.png): visual proof of concept for a richer, coherent medieval city. **Concept illustration, not an implemented game screenshot.** Warm limestone, timber framing, slate and terracotta roofs, burgundy market awnings, greenery, clear paths and soft directional lighting.

The next art step is a playable representative scene using optimized original assets, with camera/collision alignment, selection readability, animation and mobile performance verified before expanding the whole renderer. A generated image alone does not establish that the running game achieves this quality or performance. Production logos also need small-size and light/dark background review before adoption.
