- Strict optional schema11; schemas1–10 retain state without invented progress. Old histories/IDs/terms remain. New512-return ledger capacity reserved before spending, no truncation.
- Prototype exposes Valewatch first; Ashford/full partner-art pass waits for owner prototype review. Keep schema/catalog interfaces ready without pretending Ashford is implemented.
