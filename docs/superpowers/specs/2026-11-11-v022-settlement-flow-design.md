# v0.22 — A quieter, living settlement

Owner delegated next-version decisions after reviewing v0.21 on desktop, requested automatic construction follow-up, modest graphics/audio improvements, possible cutscenes, and proverbs/poetry. Mobile work remains paused. Base: released main 772b191. No merge or deployment is authorized by implementation.

Chosen approach: improve the existing single-file Canvas game in place. Keep right-click orders and drag panning, prevent the browser context menu throughout the gameplay surface, and retain one building inspector rather than duplicating information in a map-drawn box. Coordinate worksite and selected-building panels. Escape and selection changes clear stale placement feedback. Deep city figures remain optional. Alternative: remove right-click altogether, which would break familiar orders; or redesign every city panel, which would expand scope unnecessarily.

When a city construction project finishes, its living friendly workers select the nearest unfinished worksite with fewer than four assigned builders, filling vacancies deterministically by distance then site id. Travel still takes time; costs, progress rates, saves and gathering do not change. Manual orders, release and cancellation always take precedence. No eligible work leaves builders idle. Existing straight-line movement has no obstacle pathfinding, so use the same travel eligibility as existing construction. Skirmish does not gain this automation.

Visual changes are limited to soft contact shadows, warm building highlights and construction details, using original Canvas artwork with bounded per-building work. No new assets, engine, economy or paid service. Audio adds a restrained completion cue through the existing effects bus, honoring mute, volume, hidden tabs and effect preferences, with a cooldown for simultaneous completions.

Cutscenes are an optional, short settlement vignette available from Chronicle, not a forced interruption. Show the real current city under a letterbox and a brief literary passage, suspend simulation using existing overview state, then restore exact view and prior pause state on Skip, Escape, timeout, restore or restart. Respect reduced motion and never auto-start audio or change resources. A small readable literature section contains verified public-domain poetry with author, work and source, plus clearly labelled original settlement sayings. No fabricated historical proverbs or unverified translations. This is the first cinematic presentation, not a new narrative campaign.

Verification: reproduce stale selection notices, duplicate canvas information and panel overlap; cover empty-map context menus, manual orders and builder capacity/ties/cancel/restore; verify vignette cleanup, keyboard/motion and sound preferences. Existing regression, packaging and smoke checks remain required. Record actual screenshots and all failures honestly.
