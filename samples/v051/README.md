# v0.51 quick playtest save

`charter-ready.json` is a real resource-funded Marches town, reached using actual gathering, paid native construction, builders and workshop production. The route was **accelerated through simulation ticks** for engineering validation; it is not evidence of a normal-clock first-13-minute playthrough. No resource, population or building grants were used.

In v0.51, open Menu → Saved city → Import and choose the JSON (the prior city is replaced only after validation). Select the Keep, review **From Village to Town**, then pay for the charter. Produce timber/planks and construct the Market loading yard with real workers, then reserve and dispatch mixed cargo. Export your own current city before replacing it.

The save starts before the charter, with the old Ironmere supplier agreement still untouched. This lets you test the new independent route quickly.
