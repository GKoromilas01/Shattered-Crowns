# v0.26 playable art sample — review only

This is a throwaway art-direction prototype built from released v0.25 f98d187. It is not v0.26, not an approved full asset set and not a deployment.

Extract this archive, open a terminal in its folder, run `python3 -m http.server 8026`, then open http://127.0.0.1:8026. A local server is recommended; no accounts or network services are required. All runtime assets are included. The ordinary game title badge remains v0.25 because that simulation is unchanged; the review strip identifies this sample.

The scene begins PAUSED without the normal dark Pause screen (suppressed only for art review). Press Resume to play. W selects workers; right-click terrain to move, a tree to gather or a foundation to build. Use existing Worksites actions to assign/release/cancel, and existing Market inspection. Selection, placement and camera remain the game systems. Enable camera unlocks edge movement. Space toggles Pause.

Use Scene to inspect:
- Opening: normal Brookstead initial state, with a fixed comparison camera.
- Developed: seeded art fixture, not a resource-funded playthrough.
- Stress: seeded fixture with222buildings,248deposits/trees,120units and1worksite, deliberately including crowded/overlapping objects.

Use View released art / View sample art to compare the same state, view, zoom and Pause. Both use the same comparison-only suppression of Pause and saying overlays. Construction stage changes the fixture's progress for art review only; it is not a gameplay button for the release.

Representative art coverage: keep, cottage, Market, oak, civilian worker poses and3cottage construction stages. Other building types use labelled markers; nonworkers/deposits are provisional. Roads/terrain/water are cached original sample drawing, not a complete final art pass. No production-chain or schema9 changes have been implemented. The full asset set and trade progression wait for sample review.

Original generated artwork: samples/v026/assets/settlement-atlas.png, authored for this project with OpenAI image generation on15November2026. No external asset pack or copied concept-image pixels. The source repository retains provenance and crop metadata. Sprite atlas alpha is composited normally; file viewers may exaggerate tiny-alpha edge colours.

manifest.json lists SHA256 file hashes, sizes and the released source revision. Rendering failure falls back to released drawing. No merge or deployment approval is implied.
